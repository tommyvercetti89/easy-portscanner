Basic Scanner performs a simple and fast TCP scan using predefined IP addresses and ports in the code block.
If you want to change the output, you need to manually edit the code block.

Good Scanner takes the IP address and port ranges from the user and performs the scan.
The scan duration may increase depending on the size of the entered port range.
The default response waiting time for each port is 1 second. The waiting time can be changed by editing the code block.

Best Scanner allows you to perform scanning without being detected by bypassing advanced firewalls.
Although scans performed with Best Scanner are slower, they are more secure.
Best Scanner not only finds open ports but also performs Banner Grabbing to reveal the technology running behind the open port to the user's screen.
This is critical in cybersecurity.

tarar.py is a multi-purpose scanning tool.
All scanning methods mentioned above are integrated into Tarar.py.
When running tarar.py, the user can choose which scanning method to use according to their needs.
With Tarar.py, you can easily test and compare different scanning strategies.
